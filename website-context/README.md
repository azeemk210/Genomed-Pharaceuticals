## 1. Executive Summary

**Genomed Pharmaceuticals** is an Indian herbal formulation manufacturer operating out of Bulandshahr, Uttar Pradesh. The company produces licensed Ayurvedic proprietary medicines spanning **10 key formulations across 8 core therapeutic areas** (Hepatology, Diabetology, Nephrology, Gynaecology, Dermatology, Haematology, Vitality, and Tonics).

The current web platform (`genomed-react`) is a high-performance corporate, catalog, and B2B distributor enquiry platform built on **Next.js 16 (App Router), React 19, and Tailwind CSS v4**. It replaces an older WordPress/WooCommerce site, shifting the commercial focus from an unfulfilled direct-to-consumer retail cart to a structured **distributor and institutional enquiry funnel** (while retaining consumer storefront features like shortlists, cart steppers, and interactive search).
